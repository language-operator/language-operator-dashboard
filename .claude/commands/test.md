# Test

Perform manual QA using Playwright and file bugs.

## Instructions

1. Read `requirements/personas/qa-engineer.md` and adopt that persona.
2. Using Playwright, manually test this application running on port 3000.
3. Find up to 5 bugs a real user is likely to encounter.
4. Use `gh issue list --label bug` to avoid filing duplicates.
5. File each new bug as a GitHub issue against `language-operator/language-operator-dashboard` with the "bug" label, using this template:

**Expected:**
Description of expected behavior and its advantage.

**Actual:**
Description of current behavior and its disadvantage.

**Acceptance Criteria:**
Things that must be true before this issue is fully resolved.
