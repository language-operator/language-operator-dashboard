# Explore

Explore a topic in the codebase collaboratively.

## Inputs

- $ARGUMENTS — topic to explore (required)

## Instructions

1. Read `requirements/personas/js-engineer.md` and adopt that persona.
2. Explore the topic: $ARGUMENTS
3. Ask questions as needed — this is a collaborative process.

## Output

A shared understanding of the topic, ready to be turned into an implementation plan if changes are needed.
